# Avtoservis Selan

Operativni sistem za delavnico Avtoservis Selan.

## Lokalni zagon

```bash
npm install
cp .env.example .env.local
npm run dev
```

Odprite [http://localhost:3000](http://localhost:3000) — preusmeri na `/dashboard`.

## Supabase

CLI je povezan z projektom `avtoservis-selan` (`verxxsjbewmkgoxwqvxo`).
Mapa `supabase/` je namenska za CLI in se ne sme brisati.

Trenutni UI uporablja samo lokalne demo podatke — brez poslovne sheme in brez zapisov v bazo.
